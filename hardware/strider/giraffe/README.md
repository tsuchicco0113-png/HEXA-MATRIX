# キリン版ボディ(ラフ v0)

CoreMatrix + 18350×2 ベース + FS90R を 1 つの体にまとめたボディ。歩行台に載せるとキリン、机用台座に載せるとチンアナゴになる構想の、ボディ部分だけ。

| ファイル | 内容 | 印刷の向き |
|---|---|---|
| giraffe_bay_x1.stl | 胴(サーボベイ)。FS90R を軸下向きに入れて耳をネジ止め | 床面を下 |
| giraffe_neck_x1.stl | 首 + 頭の受け。スカートを胴に差し込み、横から M2 タッピング 2 本 | スカートを下。首の付け根の広がりと棚の下にサポート |

- 頭は前の体モジュールより 30 mm 上、18 mm 前(`GIRAFFE_RISE` / `GIRAFFE_DY` で変更可)
- 底面・ホーン位置は horn_hub と同じ。ドック(歩行台側)と台座はまだラフで STL 未出力
- FS90R の耳ピッチ 27.7 mm は推定値。実物で確認してから本番印刷
- 生成: `python cm_giraffe.py`(stackchan-strider の walker/ に置いて実行)
